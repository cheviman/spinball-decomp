# The four bonus stages from Toxic Caves: the level select's flag poked on as in the tables' scripts (FFF8F8),
# no button at the start (Toxic Caves), then the tables' fixed pattern of flippers and moves from frame 1000 to
# the end, in the tables and in the stages alike. 0FA588 is the bonus stage, run whole inside the step that
# calls it; its argument picks the stage (FF3CBC: 0 -> 1, 1 -> 2, 2 -> 0, 3 -> 3, 0FA59A-0FA5C8). Two steps call it:
# - mode 3 (FF3CB4, a long: FF3CB7 its low byte), which 0E1CAE sets when a table's multiball object is hit
#   ("* ENTERING MULTI BALL *") with the count FFF1FA at 78h: when the count runs out 0D5356 runs 0FA588(0).
#   Poked at 1200 as 0E1CAE sets it: stage 1 (FF3CBC), frames 1350-7025.
# - mode 6's step 11h (FF55A0, 0D4DB6), with FF41C2 clear and bit 7 of the player's byte at +0C (FF5764) clear
#   (a drained ball leaves it set, and the step then skips the stage): the player's word at +30 (FF5788, the
#   table) goes up by one, and while it is under 4 0FA588 runs with it, then 0D3FAC starts the next table.
#   Poked at 7200 (the table 0: stage 2, frames 7225-12525, then Lava Powerhouse), 12900 (stage 0, 12925-16325,
#   then The Machine) and 16700 (stage 3, 16725-19250, then Showdown), each in a table's play (mode 2).
# The frames are those of a run with the Z80 on (--z80-rom-reads), as the tables' scenarios run: without it the
# 68000 loses no time to the Z80, the stages end at other frames and the pokes fall inside them.
