# The plan

The decompilation follows the method arcade-decomp's games follow (TMNT, OutRunners, SegaSonic, The Simpsons):
C that does exactly what the original does, checked frame by frame against the reference, with nothing of the
ROM in the game. The decompilation is only that: what is later built on the finished C is a project of its own,
and nothing of it (speed, optimisation, new targets) decides or goes into this one.

Each step has the check that says it is done.

| # | Step | Done when | Status |
|---|---|---|---|
| 1 | Reference: the original on MAME's cores against console-decomp's Mega Drive (`mdref`) | the game boots, plays every table, sounds; two runs give the same hashes | done (picture from the model's VDP; MAME's VDP as the picture's reference: to do) |
| 2 | Scenarios: control scripts through the whole game | the attract, the four tables, the bonus stages, the multiball, the bosses, the options, 2-4 players, game over, the ending | 4 of them (`tests/controls`: the four tables' starts) |
| 3 | Static analysis without traces | every address the scenarios execute found (now 17,399 of 17,399), and the rest of the code classified | done for what runs |
| 4 | Coverage: every byte of the cartridge explained | 0 unknown bytes; every read table described in `symbols.txt` | 6,010 unknown, 25,837 read but not described; 728,791 described (69.5%); what each reader (the profile's READERS) read that no table describes: 0 but the plane drawers' 52 bytes of texts and the C2 decoder's 1 past the cutscene's tiles |
| 5 | The data with names and types, and the assets in editable formats with `--check` | sprites and tilesets as PNG (SSC, C2/LZW and the raw sprites), levels, splines, objects, animations, palettes, texts, GEMS music and samples; the tables' values by the level (palettes, sizes, starts, music, countdowns, and the tables the code reads by the level); the collision: each table's 16x16 sectors of segments and circles, and the flippers (their places by the table, the shapes of their collision by their position, their boxes), walked from the code, every byte the collision code reads in the scenarios walked, as text that builds back identical, with a picture of each table's collision;
