# Sonic the Hedgehog Spinball (Mega Drive / Genesis, USA, GM MK-1537 -00) - 68000 program symbols
#
# Addresses and names only: no game data lives in this file.
# Format:  ADDRESS  KIND  NAME  [LAYOUT]   [# comment]
#   KIND: func = function entry, code = code label, data = data label
# Addresses are the 68000's, 000000-0FFFFF (the cartridge; the program has no mirrors).
#
# LAYOUT, for data tables that hold code addresses the analysis cannot see the code load
# (tools/core/m68000/analysis.py reads record=, code= and count=):
#   record=N        the table is an array of N-byte records
#   count=N         ... of N records
#   code=A          every record holds a 32-bit code address at offset A
# Sizes, offsets and counts are decimal.
#
# The analysis starts at the exception vectors (the reset at 000200, the VBLANK's at 0D3D4C) and finds the code
# without traces, following what the address registers hold, the C compiler's switches, the registers its calls
# keep and the tables read relative to the PC (tools/game_profile.py); the lines here are what it cannot work
# out, each with how it was found (mdref --jumps: where a jump through a register went).

# ======== functions ========

# makes an animated object from a definition (its first argument: tools/data_walk.py reads what the code hands it),
# at a place and with flags (0D5F16-0D60E0)
0D5F16  func  make_animated_object
# the animated object of a game object (the first argument: FF784C on, 34 bytes each), from a definition (the
# second), at the object's place (fields 12, 14), unless its field 0 already keeps one (0E1ECA-0E1F46); and its end
# (field 22 bit 15 of the animated object, field 0 cleared: 0E1F48-0E1F5A)
0E1ECA  func  make_object_animated
0E1F48  func  end_object_animated
# an animated object from a definition (the second argument) at the place the third and fourth give, kept in the
# long at +4 of the first (0E1F5C-0E1FC4); and its end (0E1FC6-0E1FDE)
0E1F5C  func  make_animated_object_kept
0E1FC6  func  end_animated_object_kept
# the tile loaders (tools/spinball_compression.py; tools/data_walk.py reads what the code hands them): SSC into
# the VRAM's tile the second argument says (0D6B88-0D6C28); a word, then that many tiles as they are, or C2 when
# it is 0 or less, into VRAM 0 (0F3BB8-0F3C04); C2 into the VRAM's address the first argument says (0F5A5E-0F5A78),
# both through the C2 decoder (0F5A7A-0F5B9C: the data at A1, the VRAM's address at A0)
0D6B88  func  load_ssc_tiles
0F3BB8  func  load_tiles
0F5A5E  func  load_c2_tiles
0F5A7A  func  decode_c2_tiles
