# Sonic the Hedgehog Spinball (Mega Drive / Genesis, USA, GM MK-1537 -00) - 68000 program symbols
#
# Addresses and names only: no game data lives in this file.
# Format:  ADDRESS  KIND  NAME  [LAYOUT]   [# comment]
#   KIND: func = function entry, code = code label, data = data label
# Addresses are the 68000's, 000000-0FFFFF (the cartridge; the program has no mirrors).
#
# LAYOUT, for data tables that hold code addresses the analysis cannot see the code load
# (tools/core/m68000/analysis.py reads record=, code= and count=):
#   record=N        the table is an array of N-byte records
#   count=N         ... of N records
#   code=A          every record holds a 32-bit code address at offset A
# Sizes, offsets and counts are decimal.
#
# The analysis starts at the exception vectors (the reset at 000200, the VBLANK's at 0D3D4C) and finds the code
# without traces, following what the address registers hold, the C compiler's switches, the registers its calls
# keep and the tables read relative to the PC (tools/game_profile.py); the lines here are what it cannot work
# out, each with how it was found (mdref --jumps: where a jump through a register went).

# ======== functions ========

# makes an animated object from a definition (its first argument: tools/data_walk.py reads what the code hands it),
# at a place and with flags (0D5F16-0D60E0)
0D5F16  func  make_animated_object

# ======== functions reached only through data ========

# the front end's sequencer (0F454A) runs scripts of commands; one of them calls a function whose address is in
# the script itself (0F47E2 "movea.l (A4)+, A0", 0F47E4 "jsr (A0)"; mdref --jumps: 0F47E4 -> 0F3B3E, 0F49B8,
# 0F4AE4, from the title screen on). Their names wait for the scripts' format.
0F3B3E  func  sequence_call_0F3B3E
0F49B8  func  sequence_call_0F49B8
0F4AE4  func  sequence_call_0F4AE4
# the same sequencer's call at 0F47E4 reaches this one too (mdref --jumps, The Machine's and Showdown's runs)
0F3676  func  sequence_call_0F3676

# the animation interpreter calls a function whose address the animation's data holds (0D5D78 "movea.l (A3), A0",
# 0D5D7A "jsr (A0)"; mdref --jumps: 0D5D7A -> 0D617A, 0D61D2). Their names wait for the animations' format.
0D617A  func  animation_call_0D617A
0D61D2  func  animation_call_0D61D2

# 0F3676 calls the function its caller hands it in A5 (0F3694 "jsr (A5)"; mdref --jumps: 0F3694 -> 0F3F7E)
0F3F7E  func  sequence_task_0F3F7E

# the VBLANK interrupt's tail (0F62B8) runs a list of tasks from FFF872: each node holds the next node's address,
# then the code to run (0F62D2 "movea.l D0, A5", 0F62D4 "jsr (4,A5)"), which 0F439C and 0F43BC put there when they
# add a node; mdref --jumps: 0F62D4 -> 0F43E0, 0F4492
0F43E0  func  vblank_task_0F43E0
0F4492  func  vblank_task_0F4492
